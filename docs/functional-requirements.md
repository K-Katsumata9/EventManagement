# 機能要件

[← 要件定義書に戻る](requirements.md)

## 1. 機能要件（最小構成）

### 1.1 イベント（予定）のCRUD
- イベントを作成できる（タイトル、日付、ステータスを設定）
- イベントの内容を編集できる（タイトル・日付・ステータス・詳細）
- イベントには詳細（説明文）を設定できる（任意項目）
- イベントを削除できる
- イベントには作成日時を自動で記録する

### 1.2 日付管理
- イベントには開始日（および任意で終了日）を設定する
- 日付はカレンダー形式の入力UI（`<input type="date">`相当）から選択する
- 一覧画面では日付順（昇順・降順）に並び替えができる

### 1.3 ステータス管理
- イベントのステータスは「予定」「対応中」「完了」の3種類から選択する
- 一覧画面でステータスごとに絞り込み表示ができる
- ステータスは一覧画面から直接変更できる（編集モーダルを開かずに変更可能とする）

### 1.4 カレンダー表示
- 月単位のカレンダーを表示し、各日付にその日のイベントを表示する
- カレンダー上のイベントをクリックすると編集モーダルが開く
- カレンダーは前月・次月に移動できる
- ステータスに応じてカレンダー上のイベント表示の色分けを行う

## 2. 操作の流れ

典型的な利用シーンにおける操作の流れは以下の通り。

1. 一覧画面またはカレンダー画面を開く
2. 「＋イベントを追加」から、イベント（タイトル・日付・ステータス）を登録する
3. 対応状況が変わったら、該当イベントのステータスを「予定」→「対応中」→「完了」に更新する
4. 内容を変更したい場合はイベントをクリックして編集、不要になったら削除する
5. カレンダー画面で月ごとの予定を俯瞰する

```
[開始] → イベント作成 → （進捗に応じて）ステータス更新 → イベント編集／削除
```

## 3. 対象外（今回は作らない機能）
- ユーザー登録・ログイン
- イベントへのラベル・添付ファイル
- 複数人での共有・招待機能
- 繰り返しイベント（定期予定）
- リマインダー・通知機能
- 週表示・日表示のカレンダー（第一版は月表示のみ）

## 4. 受け入れ基準（完成の判断基準）
以下がすべて満たされた状態をもって、第一版の完成とする。
- イベントの作成・編集・削除ができること
- イベントのステータス（予定／対応中／完了）を変更でき、変更後も状態が保持されること（画面を再読み込みしても内容が消えないこと）
- 一覧画面で日付順の並び替え、ステータスでの絞り込みができること
- カレンダー画面で月単位の表示・月の切り替えができ、該当日のイベントが表示されること
- PCの主要ブラウザ（Google Chrome最新版）で問題なく表示・操作できること
