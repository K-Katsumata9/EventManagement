# データベース設計

[← 要件定義書に戻る](requirements.md)

## event（イベント）
| カラム名 | 型 | 説明 |
|---|---|---|
| id | 数値 | 主キー |
| title | 文字列 | イベントのタイトル |
| description | 文字列（任意） | イベントの詳細（補足内容）。未設定可 |
| start_date | 日付 | イベントの開始日 |
| end_date | 日付（任意） | イベントの終了日。未設定の場合は単日イベントとして扱う |
| status | 文字列（enum想定） | ステータス（`scheduled`＝予定／`in_progress`＝対応中／`done`＝完了） |
| created_at | 日時 | 作成日時 |
| updated_at | 日時 | 更新日時 |

## 備考
- 第一版では単一テーブル構成とし、カテゴリ・タグ・担当者などのマスタは持たない
- ステータスはRails側でenumとして管理し、DB上は文字列（またはinteger）カラムとして保持する想定
- `start_date` にインデックスを張り、一覧・カレンダー表示での日付範囲検索を高速化する
